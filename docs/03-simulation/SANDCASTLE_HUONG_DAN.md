# Bài thử Cesium Sandcastle — Ngày 8

1. Mở https://sandcastle.cesium.com/.
2. Tìm ví dụ `Hello World` hoặc mở https://sandcastle.cesium.com/index.html?id=hello-world.
3. Trong khung JavaScript, thay nội dung bằng code trong `sandcastle-prototype.js`.
4. Chạy thử (nút Run; giao diện có thể thay đổi).
5. Xác nhận thấy địa cầu, trạm xanh, điểm giao cam, waypoint UAV vàng, tuyến đỏ.
6. Thử pan/zoom/rotate; mở bằng điện thoại nếu có thể.
7. Chụp hình, ghi thiết bị, trình duyệt, thời gian, vấn đề gặp phải vào file `sandcastle-results.md`.

**Chú ý:** Đây là mô hình marker và đường bay tĩnh dùng để kiểm tra Cesium, chưa phải flight simulator và chưa có drone 3D glTF. Nếu trang yêu cầu ion token, làm theo hướng dẫn tài khoản miễn phí và điều khoản dịch vụ; không đẩy token bí mật vào repository.
