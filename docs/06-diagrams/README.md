- Đây là sơ đồ PHÁC THẢO. Hãy bổ sung lỗi, xung đột, quyền, checkpoint và điều kiện chuyển trạng thái.
- File `03-use-cases.mmd` là biểu diễn chức năng bằng Mermaid flowchart, KHÔNG phải UML Use Case notation chuẩn. Muốn UML Use Case chuẩn, dùng diagrams.net hoặc PlantUML.
