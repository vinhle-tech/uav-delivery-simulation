# UAV Delivery Simulation System

## 1. Giới thiệu

Hệ thống điều phối, giám sát và mô phỏng UAV giao hàng
chặng cuối trên Web, Mobile và Desktop.

## 2. Mục tiêu

- Mô phỏng đội UAV giao hàng.
- Xây dựng bộ điều khiển UAV ảo.
- Quản lý đơn hàng và nhiệm vụ bay.
- Giám sát telemetry theo thời gian thực.
- Đồng bộ dữ liệu giữa ba nền tảng.

## 3. Công nghệ dự kiến

- Frontend: React, TypeScript, Vite
- Backend: Node.js, Express
- Realtime: Socket.IO
- Database: PostgreSQL
- Simulation: CesiumJS
- Mobile: Capacitor
- Desktop: Electron

## 4. Thành viên

- TV1: Frontend & UI/UX
- TV2: Backend & Database
- TV3: Simulation & Flight Controller
